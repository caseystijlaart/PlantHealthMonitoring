= Prototype 1 Validation (POF-03 extension)
:toc:

== Scope

This prototype extends POF-03 with:

* ML-driven forecasting for *time-to-next-watering* and *time-to-humidity-drop*.
* Dynamic duty-cycling to reduce average power usage (less frequent wakeups when plants are stable).

== Architecture changes

=== New predictive model

`PredictiveIrrigationModel` was added and trained online from rolling history.

* It performs lightweight linear regression over recent samples.
* It predicts when soil moisture or humidity crosses plant thresholds.
* No fixed static schedule is used; schedule is continuously updated from live data.

=== Recommendation upgrade

Recommendations now include:

* `predictedMinutesToWater`
* `optimizedCycleMinutes`
* `estimatedPowerSavingPct`

== Power optimization method

Baseline polling interval from POF-03 is assumed as 30 minutes.
The prototype computes:

[source]
----
optimizedCycleMinutes = clamp(min(predWater, predHumidity) * 0.5, 15, 240)
powerSavingPct = (1 - baselineCycle / optimizedCycle) * 100
----

This keeps the system responsive near stress events while increasing sleep intervals when stable.

== Validation results (example run)

[cols="1,1,1,1",options="header"]
|===
|Scenario |Predicted watering need |Optimized cycle |Estimated power saving
|Drying slowly |480 min (8h) |240 min (4h) |87.5%
|Moderate trend |180 min (3h) |90 min |66.7%
|Urgent |20 min |15 min |0%
|===

Interpretation:

* When the model forecasts low short-term risk, the device sleeps longer and saves energy.
* When risk is near, cycle time contracts automatically.

== Notes

This is suitable for embedded constraints (no heavy cloud dependency), while still using ML-style prediction that adapts to sensor trends.
