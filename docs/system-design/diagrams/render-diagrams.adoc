== Flow chart: boot part 1 (provisioning + connectivity)

[plantuml, target=flow-boot-1]
....
@startuml
start
:Read device_id from NVS
Derive device name from MAC;
if (Pairing document\non LittleFS?) then (no)
  :RunProvisioningMode
  (BLE, advertise PHM-XXXXXX);
  :Re-read pairing document;
else (yes)
endif
:CloudService.SetConfig
+ Log.configure;
:WiFi: SetCredentials
+ EnsureConnected;
if (WiFi connected?) then (yes)
  :NTP sync, set start time,
  UpdateLastSeen,
  ReportModelVersion;
else (no)
endif
:continue in part 2;
stop
@enduml

== Flow chart: loop, 5-second tick

[plantuml, target=flow-loop-5s]
....
@startuml
start
:5 s command tick;
:Reconnect WiFi if down;
if (Plant label empty\nand device_id set?) then (yes)
  if (FetchPlantLabel\nsucceeded?) then (yes)
    :Fetch profile, set it,
    run first cycle,
    UpdateLastSeen;
  else (no)
    if (Grace period\nexpired (30 ticks)?) then (yes)
      :PerformFactoryReset; <<#pink>>
      stop
    else (no)
      :Log grace-period count;
    endif
  endif
else (no)
endif
if (trigger_reset set?) then (yes)
  :PerformFactoryReset; <<#pink>>
  stop
else (no)
endif
if (trigger_measurement set?) then (yes)
  :RunMonitoringCycle
  + UpdateLastSeen;
else (no)
endif
:Log.uploadPending;
stop
@enduml
